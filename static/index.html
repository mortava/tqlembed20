Frequently asked questions

How is File Search different from a regular vector database?
File Search is a fully managed RAG service — upload a file and query it immediately. No embedding pipelines, no index management, no infrastructure. Google handles chunking, embedding (gemini-embedding-2), indexing, and retrieval automatically.
What file formats are supported?
PDF, DOCX, TXT, Markdown, CSV, JSON, and most code file types up to 100 MB each. Images (PNG, JPEG) are supported with the multimodal gemini-embedding-2 model. Audio and video are not currently supported.
How long are my files and embeddings stored?
Raw files are deleted after 48 hours. Embeddings in your File Search Store are stored indefinitely until you manually delete them — there is no TTL on the index.
What does it cost?
Storage and query-time embeddings are free. You pay for indexing (when you first upload) at the gemini-embedding-2 rate, plus normal Gemini input/output token costs per query.
Can I filter results by document metadata?
Yes — attach key-value metadata to any document at upload time and filter at query time. Example: program = "DSCR" or year >= 2025. Full AIP-160 filter syntax supported.
Where can I submit a loan?
Submit at submit.tqltpo.com — TQL's full-service TPO portal for Non-QM and DSCR submissions.
